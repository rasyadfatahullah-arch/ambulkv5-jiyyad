# JIYYAD TOOLS — AM BULK V5 (Secure)

Versi aman dengan proxy server.  
Tidak ada CORS error, API endpoint tersembunyi.

## Cara Menjalankan

```bash
npm install
npm start
```

Lalu buka: **http://localhost:3000**

## Struktur

```
am-bulk-v5-secure/
├── server.js          ← proxy (API call di sini)
├── package.json
├── public/
│   └── index.html     ← UI
└── README.md
```
